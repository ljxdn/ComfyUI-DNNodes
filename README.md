# ComfyUI-DNNodes

给 **MiniMax H3** 视频工作流用的三个 ComfyUI 自定义节点：把「一张资产卡（图 / 音 / 描述）」
直接喂给导演台的分段（r2v 分组），需要时再把分组拆回逐个素材口去接官方工作流，
并附带一整套顺手的编辑体验（单端口多连线、选中高亮上游、提示词富文本编辑器）。

![DN 节点效果展示](<assets/DNnodes效果展示.jpg>)


---

## 节点

| 节点 | 节点 id | 作用 |
|---|---|---|
| **资产卡** | `H3MediaLoader` | 一张资产：图像（可粘贴截图 / 拖放 / 输入目录下拉）+ 音频（波形、播放、裁剪、静音）+ 资产描述；另有「资产名」「最长边」。输出 `media / image / audio / prompt` |
| **资产卡 to Director Group** | `DNMediaToDirectorGroup` | 把若干张资产卡打包成 **MiniMax H3 Director** 的 Reference-to-Video 分组（`MMX_DIR_GROUP`），可直接接导演台或 `Groups Combine` |
| **资产卡Group拆分** | `DNGroupSplit` | 反过来：把一个 `MMX_DIR_GROUP` 拆回**逐个素材口**（`image_1..9` / `video_1..3` / `audio_1..3`）+ 最下方一个 `prompt` 文本口，用于接 **MiniMax H3 官方工作流** 的逐口接线方式 |

`medias` 端口可**接多条连线**（最多 9 条），编号顺序 = 连线顺序 = 提示词里
`<Picture N>` / `<Audio J>` 的编号。拆分组出来的口顺序与编号一致：
图片在前、视频其次、音频在后，`prompt` 在最下面。

## 安装

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/ljxdn/ComfyUI-DNNodes.git
```

重启 ComfyUI。依赖：ComfyUI 本体自带的 `torch` / `numpy` / `Pillow`，**无需额外 pip 包**。

想用第二个节点的输出，需要另外安装
[ComfyUI_MiniMaxH3_Director](https://github.com/AIMixer/ComfyUI_MiniMaxH3_Director)（Apache-2.0）。

## 功能

### 资产卡

- **图像**：输入目录下拉 / 拖放 / 截屏后**一键粘贴**（图片区右上角剪贴板按钮，或鼠标停在图片区按 `Ctrl+V`）；
  同内容重复上传按 MD5 去重，不会堆文件。
- **音频**：波形上拖选区间 → `裁剪` 写回 `trim_start` / `trim_end` / `还原`；`静音` 时输出 `audio = None`。
- **最长边**：参考图最长边超过该值即等比缩小（只缩不放），默认 1440。
- **资产名**：参与「提示词里没提到的资产会被跳过」这一过滤规则；
  同时会以**大号字体（20px，比节点标题大一号）显示在节点标题栏下方**那一行空白里 ——
  左对齐、超长自动 `…` 截断，卡片一多也能一眼认出谁是谁。

### 资产卡 to Director Group

- **单端口多连线**：往 `medias` 拖第 2 条线时，自动把你原本那条也收编进来，一张都不丢；
  点一下线中点的圆点即可「**本段不带音 / 本段带音（恢复）** / 序号提前 / 序号退后 /
  删除这条连线 / **替换这张卡…**」，节点右键菜单可「清空全部连线 / 连线顺序反转」。
- **段级音频开关**：卡片自己勾静音（`audio_muted`）是**卡级**的 —— 同一张卡被多个段引用时
  一勾全没。右键连线圆点的「本段不带音」只关**当前这个节点这一段**的音，图照送、编号不变
  （圆点变琥珀色示意）；同一张卡 A 段带音、B 段不带音互不影响。
  实现：连线记录里只写 `skip_audio` 标记，注入 prompt 时按连线顺序拼成 `link_audio_mask`
  （如 `"101"`），后端在**角色过滤之前**按位摘音 —— 缺位一律按「带音」处理，老工作流零影响。
- **音频超 3 条不炸节点**：MiniMax H3 只收 `<Audio 1>…<Audio 3>`，以前第 4 条音直接 `ValueError`
  整个节点跑不了；现在改为**截断保留前 3 条**（按连线顺序），其余丢弃，
  并在 ComfyUI 控制台打印一条人话说明（截了几条、怎么腾位置）。参考图超 9 张仍保持报错
  （那属于接线错误）。
- **圆点数字 = 实际编号**：显示的是这张卡在后端真正占的 `<Picture N>` / `<Audio J>`；
  被跳过的卡（资产名没写进提示词）**不吃号、也不画数字** —— 圆点上的数字永远等于喂进模型的编号。
- **被跳过的卡会显形**：后端只收「资产名出现在提示词里」的卡（与上游同一规则）；
  这些卡在画布上画成**灰色虚线 + 灰点**，选中时它们的金圈也变灰圈，
  同时编辑框上方出现一条琥珀色提示条列出是哪几张 —— 不再有"连了却没生效"的黑盒。
- **提示词空着 = 一张都没引用**：一个字都没写时，带资产名的卡全部按**未引用**画
  （灰色虚线 + 不画数字），而不是像以前那样配着 3 条绿线 1/2/3 假装已生效 ——
  这和后端一致（此时后端 `role_name not in ""` 恒真，一张都不会收）。
  把资产名写进提示词，对应的卡立刻变回绿线并拿到编号。
- **选中即高亮上游**：选中该节点时，它这一段真正吃进去的卡与中间节点会亮起琥珀金，
  一眼看清「这条用了哪几张卡」。
- **提示词富文本编辑器**：`<Picture N>` 显示成带缩略图的芯片（鼠标悬停出大图）、
  `<d>[Chinese] …</d>` 显示成对话块（按说话人着色）、`[Shot N]` 显示成镜头徽章、
  六段式标题高亮；`@` 唤起上游素材菜单；「原文 ⇄ 美化」一键切回纯文本。
- **高亮画在节点之上**：ComfyUI 里节点自绘 UI 是真 DOM 元素，canvas 上画的线永远在它下面；
  本包额外挂了一层 DOM 覆盖层，所以高亮不会被资产卡挡住。

### 资产卡Group拆分

- **输出口数量 = 上游实际素材数**：接上一个 `MMX_DIR_GROUP` 后，节点会按「后端真正会打包进去的
  数量」自动开出对应个数的素材口（资产名没写进提示词的卡不算、没选文件的卡也不算，
  与上游同一条规则），上方三个数量控件（`image_count` / `video_count` / `audio_count`）也可以手改。
  **上游一个素材都给不出时就是 0 个素材口**（只留最下面的 `prompt`）——
  这时上游的分组节点自己也会报「至少需要一段提示词，或一组参考图 / 参考音频」。
- **上游变了会自己跟上**：往本节点接线、画布上拖完一条线松手、以及每 600ms 一次的轻扫描
  —— 上游换卡 / 改资产名 / 改提示词 / 加删连线，口数都会跟着变，不用手动干预。
- **已经连出去的口不会因为上游变少而被删**：宁可暂时多留一个口（标题栏补一个 ⚠ 说明
  "口数不是上游原话"），也不会悄悄把下游的线扯掉；等上游再给出这么多、或你手动点
  「按上游刷新」，提示自然消失。
- **状态字写在节点标题栏右侧**，一眼看出"现在的口数是哪来的"：
  标题栏只写数量（`2图 1音` / `固定 9+3+3` / `0 素材`）；
  **接了线但认不出上游**时是琥珀色的 `⚠ 未识别上游`。
  `group` 口**还没接线**时标题栏留白 —— 那是"还没开始"，不是故障。
- **「按上游刷新」按钮只写这四个字**（不背状态）。自动更新没跟上、或想强制重新对账时点它；
  来龙去脉（上游是哪个节点、读写到的数量、认不出的原因 / ⚠ 的原因）会打到浏览器控制台，
  不占界面。
- **固定 9+3+3 开关**：勾上「固定 9+3+3 输出口」后，无论上游几个素材都**一次把口接满**
  （9 图 + 3 视频 + 3 音频 + 1 提示词），以后再换上游就不用动下游连线；
  没用到的口输出空值，挂在它后面的分支会被**静默剪掉**、不报错。
  **关掉时回到打开它之前的数量**（节点会记住那一刻的值，再按上游实际情况修正）。
- **认哪些上游**：① `资产卡 to Director Group` 的 `group` 输出（主力）；
  ② 官方 `ref_image_N` / `ref_audio_N` 这类逐口接线节点（按已连线的口数算）；
  ③ `Groups Combine`（**只算第一个分组**，与后端 `as_group` 口径一致）；
  ④ 中间隔了一层 Reroute 之类的中转节点也能穿过去认。
  四种都认不出来时不猜、保留现有口数并亮 ⚠。
- **prompt 口固定在最后**：素材口怎么增删，它的下标都不动，断开再接不用重连。
- **只拆不判**：本节点不做过滤之外的任何改写 —— 编号顺序、素材内容与上游分组完全一致，
  过滤规则也只在「资产名没出现在提示词里」这一条上与上游对齐（这是后端本来就有的行为）。
- **纯搬运，不吃显存**：素材只是从分组字典里取出来原样递下去，不复制、不转码。

### 替换这张卡

连线圆点菜单 →「**替换这张卡…**」：搜索栏 + 卡列表（缩略图 / 资产名 / 图·音组成 / 文件名），
列出工作流里**除本组已连之外**的所有资产卡；鼠标悬停看大图，点一下就换。

![替换这张卡](<assets/替换这张卡.png>)

- **同名换源**（重截图、换更好的参考图）：只换连线，提示词一个字不动。
- **换角色**（资产名也变）：先弹确认框，逐条列出「提示词将替换 N 处『旧名 → 新名』」的上下文、
  编号变化（`<Audio 2>` → `<Audio 1>` 这类）、以及警告（如新卡没有音频、
  旧卡的 `<Audio 2>` 将失去对应物）。三个出口：**替换并改提示词** / **只换连线** / 取消。
- **多组联动**：同一张卡还连在别的组里时，确认框多一个复选框
  「同时替换其它组里的同一张卡（N 处，各自改提示词）」—— 每个组的提示词各自重写；
  已经连着新卡的组自动跳过（否则会被去重逻辑静默丢线）。
- **可撤销**：换完的提示条带「撤销」，连线与提示词作为**同一个快照**一起还原。
- 编号重映射按「引用还是那个角色的素材」算，并且是对着**改名后的最终状态**算 ——
  换了角色后新卡会被计入编号，不会把不该动的 token 也改掉。

### 顺手修的一个导演台问题

`dn_continuity_guard.js`：导演台在重建外接组片段时会丢掉每段的 `continuityFromPrev`
（导致「引用上段」被静默改回开启、并连带二采缓存失效）。本扩展只在前端补回该字段，
**不修改导演台源码**。相关分析见
[AIMixer/ComfyUI_MiniMaxH3_Director#198](https://github.com/AIMixer/ComfyUI_MiniMaxH3_Director/issues/198)。

## 兼容性

- 节点 id、控件 key、工作流保存格式**全部保持向后兼容**。
- 后端同时支持新式 `comfy_api.latest.io` 与旧式 `INPUT_TYPES`（缺 `comfy_api` 的宿主自动回退）。
- 前端扩展均为可插拔：删掉对应的 `web/js/*.js` 即可单独关闭某项功能。
- 新增/改动 `WEB_DIRECTORY` 需要重启一次 ComfyUI；之后只改 js 刷新页面即可。
